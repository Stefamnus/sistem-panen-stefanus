# Sistem Pencatatan Hasil Panen

## Deskripsi

Proyek ini merupakan program Python sederhana untuk menghitung total hasil panen berdasarkan jumlah hasil panen dalam kilogram dan harga per kilogram. Program ini juga dilengkapi dengan fitur perhitungan diskon untuk menghitung total harga setelah mendapatkan potongan.

## Cara Menjalankan Program

Pastikan Python telah terinstal pada komputer. Clone repository ini ke komputer, kemudian buka terminal pada folder proyek dan jalankan perintah berikut:


python panen.py


Program akan menampilkan jumlah hasil panen, harga per kilogram, total hasil panen, serta total setelah diskon.
